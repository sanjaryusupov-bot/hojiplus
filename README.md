# 📦 Учёт закупа и продаж (Streamlit + Google Таблица)

Ты вводишь данные в приложении → они сразу пишутся в твою Google Таблицу.
Приложение показывает закуп, продажи, расходы, основной баланс, маржу, остатки, графики и выгружает данные за любой период в Excel/CSV.

## Что нужно от таблицы
Вкладки с точными названиями: **Закуп, Продажи, Расходы, Касса**.
Заголовки в 4-й строке, данные с 5-й (так, как в файле, который я сделал раньше).
Остальные вкладки («Сводка», «По товарам») приложению не мешают.

## Шаг 1. Доступ к таблице (один раз, ~5 минут)
1. Открой https://console.cloud.google.com → создай проект (любое название).
2. «APIs & Services» → «Library» → включи **Google Sheets API**.
3. «APIs & Services» → «Credentials» → «Create credentials» → **Service account** → создай.
4. Открой созданный сервисный аккаунт → вкладка «Keys» → «Add key» → **JSON**. Скачается файл.
5. В файле найди `client_email` (что-то вроде `...@...iam.gserviceaccount.com`).
6. Открой свою Google Таблицу → «Настройки доступа» → добавь этот email с правом **Редактор**.

## Шаг 2. Настройки (secrets)
Скопируй `.streamlit/secrets.toml.example` в `.streamlit/secrets.toml` и заполни:
- `sheet_id` — не нужен, твоя таблица уже прописана в `app.py` (указывай, только чтобы сменить таблицу);
- блок `[gcp_service_account]` — значения из скачанного JSON-файла;
- `currency` — валюта рядом с суммами (необязательно);
- `app_password` — пароль на вход (**обязательно ставь, если приложение в интернете**).

## Шаг 3а. Запуск на компьютере
```
pip install -r requirements.txt
streamlit run app.py
```

## Шаг 3б. Запуск в интернете (чтобы открывать с телефона)
1. Залей папку в **приватный** репозиторий GitHub (файл `secrets.toml` НЕ загружай — он в `.gitignore`).
2. https://share.streamlit.io → «New app» → выбери репозиторий и файл `app.py`.
3. «Advanced settings» → «Secrets» → вставь содержимое своего `secrets.toml`.

## Как пользоваться
- Слева выбираешь период — все цифры, таблицы, графики и выгрузка подстраиваются.
- Вкладки «Закуп», «Продажи», «Расходы», «Касса»: сверху форма, ниже записи за период.
- Фирма, товар и статья расходов — выпадающий список из прошлых записей (самые частые сверху). Новое название просто впиши.
- После сохранения дата и фирма остаются, чтобы быстро вносить несколько позиций подряд.
- «↩️ Отменить последнюю запись» очищает последнюю строку в таблице. Всё остальное можно править прямо в Google Таблице.
- Выгрузка (xlsx / csv) — слева внизу, за выбранный период.

## Как считается
- **Основной баланс** = бюджет из кассы + продажи − закуп − расходы (накопительно до конца периода).
- **Себестоимость** = проданные шт × средняя цена закупа этого товара.
- **Валовая прибыль** = продажи − себестоимость. **Чистая** = валовая − расходы.
- **Маржа** = валовая прибыль / продажи.
- Данные обновляются каждые 2 минуты или кнопкой «🔄 Обновить данные».
